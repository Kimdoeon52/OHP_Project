## 0. AI에게 먼저 읽힐 요약

`Stolen Time`은 **Safe Room에서 계획을 세우고, 60초 제한 안에 한 층을 돌파하는 타일 기반 시간제한 로그라이크**이다.

핵심은 다음 3가지다.

1. **계획과 실행의 분리**
   - Safe Room에서는 시간이 멈춘다.
   - 플레이어는 지도, 인벤토리, 장비, 포션, 스크롤을 정비한다.
   - Safe Room을 나가면 다시 돌아갈 수 없고, 60초 실행 단계가 시작된다.

2. **시간이 가장 중요한 자원**
   - 모든 행동은 시간/쿨타임 비용을 가진다.
   - 몬스터 처치는 위험하지만 시간 보너스를 준다.
   - 아이템 줍기, 상자 열기, 열쇠 사용도 시간 비용이 있다.

3. **짧은 런 안에 압축된 로그라이크 의사결정**
   - 1회 런은 약 15~25분.
   - 총 15층, 3개 영역, 3개 보스 구조.
   - Pixel Dungeon 계열의 아이템, 감정, 저주, 강화, 포션/스크롤 상호작용을 짧은 세션으로 압축한다.

## 2. 세계관 / 서사

### 배경

하데스는 더 이상 죽은 자만 거두지 않는다. 그는 산 자들의 시간을 빼앗아 저승의 문을 넓히고 있으며, 저승의 침식은 지하에서부터 지상을 향해 번지고 있다.

플레이어는 빼앗긴 시간을 되찾기 위해 아래층으로 내려간다. 최종 목표는 저승의 중심에서 하데스를 쓰러뜨리고 산 자들의 시간을 되찾는 것이다.

### 시스템과 서사의 연결

| 시스템 | 서사적 근거 |
|---|---|
| 60초 시간 제한 | 저승의 침식이 산 자의 생명을 갉아먹기 때문에 머무는 시간 자체가 비용 |
| 몬스터 처치 → 시간 보너스 | 하수인이 품고 있던 시간 조각을 회수 |
| Safe Room 시간 정지 | 저승의 틈새에 있는 결계 지대 |
| 최종 보스 하데스 | 산 자들의 시간을 되찾기 위한 최종 대결 |

## 5. 코어 게임플레이 루프

### 5.1 1회 런 단위

```text
런 시작
→ 1층 Safe Room 진입
→ 계획 / 정비 / 상점 이용
→ 60초 실행 단계
→ 출구 도달
→ 다음 층 Safe Room
→ 5층 / 10층 / 15층 보스전
→ 사망 또는 클리어
```

### 5.2 1개 층 단위

```text
Safe Room 입장
→ 지도 확인 / 인벤토리 정리 / 장비 교체
→ 실행 시작
→ 이동 / 전투 / 아이템 획득 / 우회 선택
→ Exit 방 도달
→ 다음 층 이동 또는 사망
```

### 5.3 한 층에서 발생하는 핵심 의사결정

1. 몬스터를 잡고 시간 보너스를 얻을 것인가, 우회해서 시간을 아낄 것인가?
2. 아이템을 주울 것인가? 아이템 줍기에는 1초가 든다.
3. Special Room을 들를 것인가? 보상은 있지만 우회 거리와 열쇠 시간이 든다.
4. 저주 정화에 정화 스크롤을 지금 쓸 것인가, 아껴둘 것인가?
5. Safe Room에서 장비를 바꿀 것인가, 현재 빌드를 유지할 것인가?

## 7. 맵 생성 시스템

### 7.1 설계 철학

이 구조를 사용하는 이유:

1. 시드 재현성 보장이 단순하다.
2. 방 단위 구성이 객체지향적으로 명확하다.
3. Floor Feeling이 Paint 단계 후처리로 들어가기 쉽다.

### 7.2 방 타입

| RoomType | 용도 | 출현 빈도 | 특이사항 |
|---|---|---|---|
| Safe | 시작점, 타이머 정지 | 층당 1개 필수 | 몬스터 진입 불가, 지도 사용 공간 |
| Normal | 일반 전투/이동 | 층당 다수 | 몬스터/아이템 배치 |
| Special | 특수 보상 | 층당 0~1개 | 상점, 보물방 등. 열쇠 필요 가능 |
| Secret | 숨겨진 방 | 층당 0~1개 | 문이 숨겨져 있음 |
| Exit | 다음 층 출구 | 층당 1개 필수 | 출구가 들어있는 방 |
| Boss | 보스전 | 5/10/15층 | 단일 거대 방 |

### 7.3 Special Room

스페셜 방은 랜덤 1개가 등장하며, 열쇠로 문을 여는 데 1초가 소요된다.

| 방 종류 | 출현 아이템/몬스터 | 비고 |
|---|---|---|
| 랜덤 상자 방 | 랜덤 상자 2~3개 | 상자 시스템 참조 |
| 몬스터 방 | 고대 골렘 | 몬스터 시스템 참조 |
| 반지 상자 방 | 반지 상자 2개 | 상자 열쇠로 1개만 개방 가능 |
| 골드 상자 방 | 골드 상자 3개 | 상자 시스템 참조 |
| 스크롤 방 | 스크롤 2~3개 | 강화 스크롤 제외 |

### 9.4 배고픔

- 배고픔은 필드에서 시간이 흐르는 동안만 감소한다.
- 음식을 먹는 경우를 제외하면 Safe Room에서는 변화하지 않는 것으로 해석된다.
- 필드 시간 10초마다 배고픔 -1.
- 최대 10, 최소 0.

| 상태 | 조건 | 시간 | 체력 변화 | 비고 |

## 12. Safe Room 설계

### 12.1 핵심 철학

Safe Room은 단순한 휴식 공간이 아니라, `Stolen Time`의 정체성을 만드는 두 모드의 전환점이다.

- Safe Room 안: 전략, 계획, 정비.
- Safe Room 밖: 전술, 실행, 반응.
- Safe Room을 한 번 나오면 다시 돌아갈 수 없다.

| 관점 | Safe Room 안 | Safe Room 밖 |
|---|---|---|
| 시간 | 정지 | 흐름 |
| 몬스터 | 진입 불가 | 활동 중 |
| 정보 | 지도 스크롤로 지형 공개 가능 | 시야 + LOS로 점진 공개 |
| 행동 | 장비 교체, 포션 사용, 인벤토리 정렬 | 이동, 전투, 투척 |
| 플레이 모드 | Strategy | Tactics |

### 12.2 지도 스크롤과의 시너지

지도 스크롤은 지형만 보여주고, 몬스터/아이템 위치는 보여주지 않는다.

의도:

1. 모든 정보를 주면 60초 실행이 단순 이동 게임이 된다.
2. 정보를 너무 안 주면 Safe Room이 무의미해진다.
3. 지형만 공개하면 길은 알지만 무엇을 만날지는 모르는 긴장감이 생긴다.

### 12.3 Safe Room에서의 의사결정

- 최단 경로 vs Special Room 우회.
- 회복 포션을 지금 쓸지, 다음 층을 위해 아낄지.
- 미감정 장비를 위험 감수하고 착용할지.
- 시간 보너스 사냥에 몇 초를 투자할지.
- 인벤토리 공간을 어떻게 확보할지.

### 12.4 상점 Safe Room

상인은 1층, 6층, 11층 Safe Room에서 등장한다.

| 등장 아이템 | 등장 확률/조건 | 개수 | 가격 | 비고 |

## 14. 메타프로그레션 / 챌린지 모드

### 14.1 설계 철학

챌린지 모드는 1회 클리어 이후의 리플레이 가치를 만든다. 같은 던전을 다른 제약 아래 다시 통과하게 하여 판단력과 숙련도를 시험한다.

핵심 원칙:

1. **의도된 비대칭**: 불편한 챌린지일수록 높은 점수 배수 제공.
2. **곱셈 누적**: 챌린지 배수는 곱셈으로 누적.
3. **시드 결합**: 동일 시드 + 동일 챌린지 조합으로 객관적 점수 경쟁 가능.
4. **회차 내 완결성**: 빌드는 매 회차 사라지고, 기록과 점수만 누적.

### 14.2 챌린지 종류

| 챌린지 | 변경 내용 | 비고 |
|---|---|---|
| 시간 압박 | 층당 제한시간 60초 → 45초 | 행동 시간 소모는 동일 |
| 보스 강화 | 보스 HP/공격력/방어력/회피/정확도 상승, 패턴 변화 | 보스 표 괄호값 적용 |
| 빈약한 강화 | 강화 스크롤 등장 수량 Area당 3개 → 2개 | - |
| 회복 봉인 | 회복 포션 효과 무효 | 흡혈, 음식, 건강한 몸 특성은 정상 작동 |
| 파편 봉인 | 몬스터 생명 파편 드랍 없음 | 처치 동기가 시간/EXP로 한정 |
| 시야 제한 | 기본 시야 -2 | Dark Feeling과 누적, 최소 시야 2 유지 |

### 14.3 점수 시스템

| 항목 | 수치 | 비고 |
|---|---:|---|
| 도달 층 보너스 | 도달 층 × 100 | 사망한 층 포함 |
| 잔여 시간 보너스 | 각 층 잔여 시간 합산 × 1 | 빠르게 클리어할수록 누적 |
| 보스 클리어 보너스 | 500 / 1000 / 2000 | 5층 / 10층 / 15층 |
| 처치 보너스 | 처치한 몬스터 시간 보너스 합 | +3/+5/+10 그대로 점수 환산 |

최종 점수:

```text
최종 점수 = 기본 점수 × (1.5 ^ 활성 챌린지 수)
```

### 14.4 시드 챌린지

| 모드 | 설명 | 시도 제한 |
|---|---|---|
| 자동 시드 | 매 런마다 무작위 시드 | 무제한 |

## 16. AI와 추가로 검토하면 좋은 핵심 쟁점

이 섹션은 다른 AI에게 문서를 먹인 뒤 바로 토론하기 좋도록 만든 질문 목록이다.

### 16.1 코어 루프 검토 질문

1. Safe Room에서 계획하고 60초 안에 실행하는 구조가 충분히 반복 플레이 욕구를 만들 수 있는가?
2. 60초 제한이 재미있는 긴장감인지, 지나친 압박인지 확인하려면 어떤 프로토타입 테스트가 필요한가?
3. 몬스터 처치 보너스가 `+3/+5/+10초`일 때, 전투가 우회보다 항상 이득이 되는 순간은 없는가?
4. 지도 스크롤이 지형만 공개하는 방식이 충분히 전략적인가?
5. 1층당 평균 30~90초 목표와 60초 기본 제한 사이의 관계가 명확한가?

### 16.2 밸런스 검토 질문

1. 이동 쿨타임이 레벨 10에서 0.05초까지 감소하면 조작/전투가 너무 빨라지지 않는가?
2. 공격/이동/아이템 사용 시간이 모두 짧은데, 60초 제한 내에서 판단 비용이 실제로 체감되는가?
3. 배고픔 상태에서 HP가 회복되는 원문 표기가 의도인지 오류인지 확인 필요.
4. Defense가 `0~N 데미지 감소` 방식이면 랜덤성이 과도해지지 않는가?
5. Evasion - Accuracy 공식의 최대 50% 제한은 적절한가?

### 16.3 구현 우선순위 질문

1. 먼저 만들어야 할 최소 프로토타입은 무엇인가?
   - 추천: `Safe Room → 60초 타이머 → 절차 맵 1층 → Exit 도달 → 몬스터 1종 → 시간 보너스`.
2. 시드 기반 결정론적 생성을 Unity에서 어떤 구조로 구현할 것인가?
3. 행동 시간 시스템을 실시간 쿨타임으로 처리할지, 내부 턴/틱 시스템으로 처리할지 결정해야 한다.
4. LOS/시야 3단계는 타일맵에서 어떻게 캐싱할 것인가?
5. 10x5 그리드 인벤토리는 장비 사이즈와 회전 기능을 지원할 것인가?

### 16.4 콘텐츠 리스크

1. 아이템/포션/스크롤/저주/마법 종류가 초기 개발량에 비해 많다.
2. 보스 3종의 패턴이 각각 별도 구현 비용을 요구한다.
3. 몬스터 상세 스탯은 많지만, 실제 전투 역할이 겹칠 수 있다.
4. Safe Room/상점/지도/인벤토리/장비/저주가 동시에 들어가야 코어 재미가 보일 가능성이 높다.
5. 모바일 출시를 고려한다면 조작계와 UI 스케일을 초기에 따로 검토해야 한다.

## 17. 개발용 최소 구현 순서 제안

### 1단계 — 코어 재미 검증

- 타일맵 이동.
- 60초 타이머.
- Safe Room 진입/퇴장.
- Exit 도달.
- 몬스터 1종.
- 몬스터 처치 시 +3초.
- 지도 스크롤 없이 기본 시야만 구현.

### 2단계 — 전략성 추가

- 지도 스크롤: 지형만 공개.
- 방 타입: Safe / Normal / Exit.
- 아이템 줍기 1초 비용.
- 포션 2종: 회복, 신속.

## 19. 현재 문서에서 확인이 필요한 모호한 부분

| 항목 | 확인 필요 이유 |
|---|---|
| 1층당 평균 30~90초 vs 제한시간 60초 | 평균 목표와 제한 시간이 일부 충돌 가능 |
| 배고픔 <= 3일 때 HP +1 | 배고픈 상태에서 회복되는 것이 의도인지 확인 필요 |
| 트롤 이동 속도 | 요약에는 0.75초/칸, 상세표에는 0.4초/칸으로 보임 |
| 레벨 10 이동 쿨타임 0.05초 | 너무 빠른 조작/밸런스 붕괴 가능 |
| 방패/Defense 계산식 | 방패, 갑옷, Defense, 강화 차감이 중첩될 때 공식 필요 |
| 보스전 시간 제한 | 보스전도 60초인지, 별도 타이머인지 명확화 필요 |
| 인벤토리 회전 | 10x5 그리드에서 1x3, 2x3 장비 회전 가능 여부 필요 |
| Safe Room에서 포션 사용 | 시간 정지 상태에서 사용 가능한 포션 범위 명확화 필요 |
| 경험 포션 | 레벨 +1 효과가 너무 강할 수 있음 |
| 시간의 포션 | 현재 층 +10초, 다음 층 -5초가 순이득이라 남용 가능성 있음 |

## 20. 한 문장 결론

`Stolen Time`의 핵심 가치는 **정지된 계획 공간과 60초 실행 공간의 강한 대비**이며, 개발 초반에는 아이템 종류를 늘리기보다 `Safe Room → 지도 기반 계획 → 60초 실행 → 몬스터 시간 보너스 → Exit 도달`의 재미를 먼저 검증하는 것이 가장 중요하다.

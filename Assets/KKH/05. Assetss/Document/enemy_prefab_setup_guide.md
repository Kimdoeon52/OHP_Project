# 적(Enemy) 프리팹 에디터 세팅 가이드

본 문서는 프로젝트의 각 구역별로 등장하는 적 캐릭터의 실제 유니티 프리팹(Prefab)을 구성하는 방법과 각 몬스터별 맞춤형 컴포넌트 설정 값을 다룹니다.

---

## 1. 공통 프리팹 구조 및 컴포넌트 체크리스트

모든 적 캐릭터 프리팹은 기본적으로 아래 구성 요소를 모두 포함하고 있어야 시스템 오류 없이 정상 작동합니다.

```
[Enemy Prefab GameObject]
  ├── SpriteRenderer (외형 이미지 렌더링)
  ├── Animator (애니메이션 상태 머신 제어)
  └── [Enemy Script] (몬스터별 개별 AI 스크립트)
```

### 필수 컴포넌트 상세 설정

#### 1) SpriteRenderer

- `Sprite` 항목은 비워두거나 기본 이미지를 올려두어도 무방합니다. (Awake 시점에 각 적의 `EnemyData` SO에 등록된 스프라이트로 런타임에 덮어씌워집니다.)

#### 2) Animator (애니메이션 컨트롤러)

적 캐릭터가 턴의 진행에 따라 이동 및 피격, 사망, 공격을 할 때 알맞은 연출을 재생하기 위해 **애니메이터 컨트롤러의 파라미터 목록**이 아래와 정확히 일치해야 합니다:

| 파라미터명   | 타입      | 역할                                                     |
| :----------- | :-------- | :------------------------------------------------------- |
| **`Walk`**   | `Bool`    | `true`일 때 걷기 상태 유지, 이동 종료 후 `false`로 리셋. |
| **`Attack`** | `Trigger` | 공격 예약 타일에 발동 시점이 도달했을 때 1회 트리거.     |
| **`Hit`**    | `Trigger` | 플레이어 공격 등으로 피해를 입었을 때 1회 트리거.        |
| **`Die`**    | `Trigger` | HP가 0 이하가 되어 사망할 때 1회 트리거.                 |

> [!IMPORTANT]
> 만약 특정 몬스터의 애니메이터에서 사망 파라미터명을 변경하고 싶다면, 스크립트 컴포넌트 인스펙터의 **`Death Trigger Name`** 필드 값을 해당 트리거 이름과 동일하게 매칭시켜 주어야 에러가 발생하지 않습니다.

#### 3) Enemy Script (최상위 부모: EnemyBase)

몬스터 종류에 알맞은 C# 스크립트를 부착하고 다음 공통 필드를 필수로 연결합니다:

- **Data**: 각 몬스터의 능력치와 보상 정보를 관리하는 `EnemyData` SO 에셋 할당.
- **Telegraph Prefab**: 공격 전 붉은색 격자 경고 타일을 띄워줄 `TelegraphIndicator` 프리팹 할당.
- **Death Destroy Delay**: 사망 트리거(`Die`) 발동 후, 씬에서 프리팹 오브젝트가 완전 소멸(Destroy)하기 전까지 애니메이션을 충분히 보여줄 대기 시간 설정 (기본값: `0.6`초).

## 2. 몬스터 종류별 상세 프리팹 설정 테이블

기획서 및 C# 코드에 기반한 각 몬스터별 연결 스크립트 및 특이 설정 매뉴얼입니다.

### [Area 1 : 하수구 테마 (1~5층)]

| 몬스터명    | 부착할 C# 스크립트 | 권장 데이터 SO (`EnemyData`) | 추가 설정 및 필수 작업                                                                                                                                                                                     |
| :---------- | :----------------- | :--------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **역병 쥐** | `EnemyPlagueRat`   | `PlagueRat.asset`            | **순수 데이터형 적**<br>별도의 추가 인스펙터 필드가 없습니다. 명중 시의 독 상태이상은 `PlagueRat` SO의 `onHitEffect` 필드에 독 효과 SO를 연결해 사용합니다.                                                |
| **거미**    | `EnemySpider`      | `Spider.asset`               | **디버프 연쇄 부여 적 (독 + 슬로우)**<br>인스펙터의 **`Slow Debuff Data`** 필드에 이동속도 감소 상태이상인 `Cripple_2t_1p.asset`을 반드시 할당해야 정상 동작합니다.                                        |
| **뱀**      | `EnemySnake`       | `Snake.asset`                | **순수 데이터형 적 (독니 물기)**<br>따로 추가 C# 코드를 작성하지 않는 데이터 기반 몬스터입니다. `Snake.asset` SO 내에서 높은 공격 딜레이(`attackSpeed` 조절)와 강한 독 데미지(`onHitEffect`)를 세팅합니다. |
| **박쥐**    | `EnemyBat`         | `Bat.asset`                  | **2칸 고속 추적형 적**<br>한 턴에 최대 2칸을 보간하며 고속 이동합니다. `Bat.asset` SO의 `moveSpeed`를 `0.5` 이하로 낮춰 설정해야 빠른 턴 속도가 유지됩니다.                                                |

| 몬스터명        | 부착할 C# 스크립트  | 권장 데이터 SO (`EnemyData`) | 추가 설정 및 필수 작업                                                                                                                                                                                                        |
| :-------------- | :------------------ | :--------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| **마법 해골**   | `EnemyMageSkeleton` | `MageSkeleton.asset`         | **직선 광선 마법 적 / 방패 소유**<br>1. `MageSkeleton.asset` SO 내 **`Has Shield`** 옵션을 **`True`**로 체크.<br>2. 4방향 직선 타일 마법 경고 및 발사를 위해 **`Telegraph Prefab`**이 필수 할당되어야 합니다.                 |
| **고블린 도적** | `EnemyGoblinThief`  | `GoblinThief.asset`          | **도주 및 아이템 탈취 적**<br>2칸 고속 이동을 활용하여 플레이어를 추적한 뒤 아이템을 탈취하여 도망갑니다. 씬에 플레이어의 인벤토리를 제어하는 `InventoryController`가 제대로 활성화되어 있어야 훔치기가 오류 없이 동작합니다. |
| **트롤**        | `EnemyTroll`        | `Troll.asset`                | **순수 데이터형 적 (강타 + 기절)**<br>느리지만 강한 한 방을 꽂는 엘리트 몬스터입니다. `Troll.asset` SO의 `onHitEffect`에 마비(Paralysis) 상태이상 데이터를 연결해 줍니다.                                                     |

## 3. 프리팹 설정 문제 해결 (FAQ)

### Q. 적이 씬에 생성은 되는데 투명하거나 외형 이미지가 보이지 않습니다.

- 부착한 C# 스크립트의 **`Data`** 필드에 `EnemyData` SO 에셋이 할당되었는지 확인하십시오.
- 할당된 `EnemyData` SO 내의 **`Sprite`** 항목에 실제 이미지 스프라이트 리소스가 정상 등록되어 있는지 보십시오. `EnemyBase`가 시작될 때 이 스프라이트 값을 `SpriteRenderer`에 자동으로 밀어 넣습니다.

### Q. 적이 플레이어를 공격하려고 할 때 `NullReferenceException`이 뜹니다.

- `EnemyBase`는 공격 턴(또는 예약 시점)에 붉은색 공격 예고 타일을 그립니다. 인스펙터 상의 **`Telegraph Prefab`**에 격자형 연출용 타일 프리팹이 빠져 있을 때 해당 오류가 발생하므로 반드시 에셋을 드래그해 놓으십시오.

### Q. 해골(Skeleton)이 뼈 방패 동작을 전혀 하지 않습니다.

- 방패 동작은 `EnemySkeleton` 및 `EnemyMageSkeleton` 스크립트에서 스탯 데이터의 `data.hasShield` 플래그를 읽어 매 턴 가동 여부를 판단합니다. 따라서 해당 프리팹에 할당된 `Skeleton.asset` 혹은 `MageSkeleton.asset` SO 인스펙터 내부의 `Has Shield` 칸을 꼭 체크하십시오.

# 60초 던전 적(Enemy) 파트 TODO 리스트 (Refactored)

GDD v1.0 및 신규 적 시스템 리팩토링 아키텍처에 맞추어 업데이트된 작업 목록입니다.

---

## 🛠️ Phase 0: 코어 시스템 확장 및 공통 로직 추출

> 개별 몬스터 구현을 시작하기 전에 반드시 완료해야 하는 핵심 선행 작업입니다.

- [ ] **EnemyData ScriptableObject 확장**
  - [ ] `attackDamage` -> `attackMin` / `attackMax` 범위형 공격력으로 변경
  - [ ] `moveSpeed` (float, 이동 비용 - 초/칸), `attackSpeed` (float, 공격 속도) 추가
  - [ ] `defenseMin` / `defenseMax` (내구성 범위) 추가
  - [ ] `evasion` (회피), `accuracy` (정확도) 스탯 추가
  - [ ] `expReward` (경험치), `goldMin` / `goldMax` 보상 스탯 추가
  - [ ] `grade` (Common/Elite/MiniBoss/Boss), `moveType` (Normal/WallPass/Stationary) 추가
  - [ ] `onHitEffect` (StatusEffectData 참조) 추가
- [ ] **EnemyBase 추상 클래스 확장 및 공통화**
  - [ ] **이동 로직 공통화**: 여러 클래스에 분산된 `TryStepTowardPlayer()` 및 `TryStep()` 공통화하여 `EnemyBase`로 추출
  - [ ] **적중 및 데미지 계산식 구현**: 회피/정확도 판정(`RollHit`) 및 방어력 감쇄(`ApplyDefense`) 로직 구현
  - [ ] **시간/턴 비용 연동**: 이동 및 공격 시 `moveSpeed`, `attackSpeed` 기반 행동 비용을 `TimeSystem`과 연동
  - [ ] **템플릿 메서드 패턴 도입**: `OnTurnUpdate` 흐름을 `공격의도발동` -> `이동수행` -> `공격예고` 3단계로 정형화
- [ ] **StatusEffect (상태이상) 시스템 설계 및 구현**
  - [ ] 독, 화상, 기절, 둔화 등 디버프 관리 매니저 구현
  - [ ] 플레이어와 몬스터 공용 상태이상 인터페이스(`IStatusEffectable`) 정의
- [ ] **기존 레거시 코드 정리**
  - [ ] 폐기된 `GridEnemyBase.cs` 제거
  - [ ] 기존 임시 적 스크립트(`KingsGuard`, `Wraith`, `Phantom`, `Crawler`)를 `Deprecated` 폴더로 격리

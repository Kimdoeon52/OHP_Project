### 2.3 차별 포인트 — 왜 이 게임이 필요한가

기존 로그라이크는 무한한 시간 위에서 공간적 위험을 푸는 장르였다. 60초 던전은 여기에 시간이라는 새로운 축을 추가한다.

계획-실행 분리 (Plan-Execute Split): Safe Room의 시간 정지는 플레이어가 차분히 사고하는 공간을 보장하면서도, 실행 단계에서는 즉각적 반응을 요구한다. 두 모드의 톤 전환이 게임의 정체성이다.

이중 의미의 몬스터 (Threat = Resource): 회피해야 할 위협이지만 처치하면 +3~+5초의 보상이 나온다. "지나쳐 갈 것인가, 사냥할 것인가"라는 의사결정이 매 턴 발생한다.

짧은 세션, 깊은 결정: 1회 런 약 15~25분. 출퇴근, 점심시간 안에 시도와 학습이 가능하다. 죽음의 비용이 낮아 실험적 플레이를 권장한다.

| 방 타입 (RoomType) | 용도 | 출현 빈도 | 특이사항 |

| Safe | 시작점, 타이머 정지 | 층당 1개 (필수) | 몬스터 진입 불가, 지도 사용 공간 |

### 6.2.1 스페셜 방 종류

스페셜 방은 아래 종류들 중 랜덤으로 1개가 등장한다. 스페셜 방들은 열쇠로 열고 들어가야한다.

열쇠로 문을 여는데 1초가 소요된다.

| 방 종류 | 출현 아이템 / 몬스터 | 비고 |
| --- | --- | --- |
| 랜덤 상자 방 | 랜덤 상자 2개 ~ 3개 | 상자 시스템 참조 |
| 몬스터 방 | 10.몬스터 시스템의 고대 골렘 등장 | 10.1 몬스터 상세의 고대 골렘 파트 참조 |
| 반지 상자 방 | 반지 상자 2개 | 상자 열쇠를 통해 1개만 개방 가능 |
| 골드 상자 방 | 골드 상자가 3개 등장한다. | 상자 시스템 참조 |
| 스크롤 방 | 스크롤이 2~3개 등장한다. | 강화 스크롤 제외 |

### 6.2.2 시크릿 방 종류

시크릿 방은 아래 종류들 중 랜덤으로 1개가 등장한다.

| 방 종류 | 출현 아이템 | 비고 |
| --- | --- | --- |
| 포션 방 | 랜덤 포션 2개 | 힘 포션 제외 |
| 장비 상자 방 | 장비 상자 1개 | 상자 시스템 참조 |
| 골드 방 | 바닥에 골드 뭉치가 3~5개가 등장한다. | 골드 뭉치는 50~75 골드 사이 중 랜덤으로 획득 |
| 인챈트 방 | 무기나 방어구에 마법을 부여할 수 있다. | 9.16의 마법 종류 중 랜덤으로 하나가 부여된다. |

### 6.3 Floor Feeling 시스템

| Floor Feeling | 효과 요약 | 시간 운용 영향 |
| --- | --- | --- |
| Hazard | 지역별 위험 바닥 생성, 하수구는 오염수, 던전은 함정, 지옥은 용암으로 표현 | 이동 시간을 2배로 걸리게 하고 올라가있는 동안 데미지를 입도록 하여 조심히 이동하는 것을 강요하여 시간 손실을 유도 |
| Dark | 기본 시야 반경 -2 | 정보 비용 증가, 횃불·심안 포션 가치 상승 |

Floor Feeling 은 Hazard/Dark 2종으로 고정한다. Traps(함정 추가 배치)는 제외한다. 함정 방·Hazard 바닥과 겹칠 때 60초 안에 층을 클리어하는 것이 비현실적으로 어려워졌다.

### 8.4 배고픔 상세

배고픔 수치로 인한 체력 +,-는 던전에서 시간이 흘러가는 시간 동안만 적용된다. 배고픔 수치의 변화도 던전에서 시간이 흘러가는 동안만 변화한다.(음식을 섭취할때 제외) 배고픔 수치는 던전에서 보내는 시간 10초에 1씩 감소한다. 배고픔 수치의 최대치는 10, 최소치는 0이다.

| 상태 | 배고픔 수치 | 시간 | 체력 변화 | 비고 |
| --- | --- | --- | --- | --- |

| 배고픔 | 배고픔 <= 3 | 10초 | +1 |  |
| 보통 | 3 < 배고픔 <= 10 | 5초 | +1 |  |

### 9.7 장비 강화 시스템

강화 시 갑옷은 데미지 감소가 늘어남. 무기는 공격력이 늘어남.

강화 시 장착 힘 요구치도 함께 낮아짐.

던전에서 줍는 장비는 강화된 상태로 등장 가능.

최대 강화 수치 15강

무기는 강화 시 최대 데미지 +2, 최소 데미지 +1

갑옷은 강화 시 최대 데미지 감소 +2, 최소 데미지 감소 +1

| 강화 단계 | 힘 요구 감소 |
| --- | --- |
| 1~3강 | -1 |
| 4~6강 | -2 |
| 7~11강 | -3 |
| 12~15강 | -4 |

| 등장 강화도 | 확률 |
| --- | --- |
| 0강 | 55% |
| 1강 | 30% |
| 2강 | 10% |
| 3강 | 5% |

| 무기 | 착취 저주 | 공격 시 15% 확률로 플레이어의 체력을 10% 앗아감 |
| 무기 | 양극화 저주 | 공격 시 150% 또는 0% 데미지, 소수점은 올림 |

### 9.10 인벤토리 시스템

인벤토리는 그리드 시스템으로 10*5 사이즈로 장비, 스크롤, 투척 무기, 유물을 저장하는데 사용된다. 플레이어가 장착 할 수 있는 아이템으로는 갑옷 1개, 근접 무기 1개, 반지 2개, 유물 1개로 이루어져있다.

### 9.11 장착 아이템 - 반지 [ 1*1 사이즈 ]

| 반지 | 강화 당 수치 변화 | 효과 |
| --- | --- | --- |
| 신속의 반지 | 쿨타임 0.05씩 추가 감소 | 이동 쿨타임 -0.1초 (최솟값 이하로는 떨어지지 않는다.) |
| 타격의 반지 | 쿨타임 0.05씩 추가 감소 | 공격 쿨타임 -0.1초 (최솟값 이하로는 떨어지지 않는다.) |
| 힘의 반지 | 추가 힘 1씩 증가 | 힘 +1 |
| 저격의 반지 | 투척 무기 강화 수치 +1 | 투척 무기가 강화 +1 된것처럼 사용된다. |
| 회피의 반지 | 회피 +5 | 회피가 +10 증가한다.(최댓값 이상으로는 올라가지 않는다.) |
| 정확성의 반지 | 정확도 +5 | 정확도가 +10 증가한다. |

### 9.14 상자 시스템

상자는 스페셜 룸이나 스페셜 룸 중 상자 룸과 일반 방, exit방들 중에서 랜덤으로 등장 할 수 있다.

상자의 보상은 투척 무기, 포션, 골드, 스크롤, 근접 무기, 방어구, 반지가 등장 할 수 있다.

상자를 여는데는 1초의 시간이 걸린다. (반지 상자 같은 경우는 열쇠로 여는 시간만 적용되어 여는데 1초만 걸린다.)

| 상자 종류 | 등장 확률 | 등장 조건 | 등장 아이템 |
| --- | --- | --- | --- |
| 랜덤 상자 | 일반 방 및 exit 방 등장 확률 20% | 일반 방 및 exit방 및 스페셜 룸에 랜덤 등장 | 투척 무기, 포션, 스크롤(강화 제외), 반지 |
| 골드 상자 | 스페셜 방 및 시크릿 방 확률 참조 | 스페셜 방 및 시크릿 방에서 등장 | 골드 100~125골드 등장 |
| 장비 상자 | 시크릿 방 확률 참조 | 시크릿 방에서 등장 | 무기, 방어구 |
| 반지 상자 | 스페셜 방 확률 참조 | 스페셜 방에서 등장(열쇠로 열어야함) | 반지 |

### 9.15 열쇠 시스템

열쇠는 방 열쇠와 상자 열쇠로 나누어져있다.

해당 층에 필요한 열쇠들은 해당 층의 일반 방이나 exit방에서 등장한다. 해당 층에서 획득한 열쇠는 해당 층에서만 사용 가능하다.

열쇠로 여는 모든 것들은 여는데 1초의 시간이 소요된다.

| 열쇠 종류 | 사용처 |
| --- | --- |
| 반지 상자 열쇠 | 반지 상자를 여는데 사용된다. |
| 스페셜 방 열쇠 | 스페셜 방을 여는데 사용된다. |

### 9.16 마법 시스템

| 분류 | 마법명 | 효과 |
| --- | --- | --- |
| 갑옷 | 공허 발걸음 | Hazard 지형을 지나갈때 이동 방해 효과 무시 및 데미지 절반 |
| 갑옷 | 마지막 질주 | 남은 시간이 10초 이하가 된다면 이동 쿨타임 -0.2초 |
| 갑옷 | 탐욕의 초침 | 상자를 여는 시간 및 아이템 줍는 시간이 0.5초로 감소된다. |
| 갑옷 | 혈시계 | 피해를 받을 때마다 25% 확률로 +1초 |
| 무기 | 흡혈 | 공격 성공 시 30% 확률로 입힌 데미지의 20% 회복 |
| 무기 | 처형 | 적의 남은 체력이 현재 무기의 최대 데미지의 절반 이하라면 즉사한다. |

| 무기 | 추격 | 적을 처치한 후 3초 동안 이동 쿨타임 -0.2초 |

# 11. Safe Room 설계 철학

### 11.1 왜 Safe Room이 핵심인가

Safe Room은 단순한 "휴식 공간"이 아니다. Stolen Time의 게임 정체성을 만드는 두 모드 전환점이다.

Safe Room을 한번 나오면 다시 돌아가지 못하도록 설계하여 플레이어가 더 신중하게 계획을 짜서 나갈 수 있도록 설계한다.

| 관점 | Safe Room 안 | Safe Room 밖 (60초) |
| --- | --- | --- |
| 시간 | 정지 (의사결정 공간) | 흐름 (실행 공간) |
| 몬스터 | 진입 불가 (RoomType.Safe로 차단) | 활동 중 |
| 정보 | 지도 스크롤로 지형 공개 가능 | 시야 + LOS 점진적 공개 |
| 행동 | 장비 교체, 포션 사용, 인벤토리 정렬 | 이동·전투·투척 |
| 플레이 모드 | 전략 (Strategy) | 전술 (Tactics) |

### 11.2 지도 아이템과의 시너지

지도 스크롤은 "지형만" 보여주고, 몬스터·아이템 위치는 가린다. 이는 의도된 비대칭이다.

1. 지도가 모든 정보를 주면 → 60초 실행 단계가 단순 운동이 됨

2. 지도가 정보를 주지 않으면 → Safe Room의 정지 시간이 무의미

3. "지형만 공개"는 두 단계의 간격을 정확히 메운다 — 길은 알지만, 무엇을 만날지는 모른다

### 11.3 플레이어 의사결정 공간으로서의 역할

Safe Room에서 플레이어가 수행하는 의사결정의 종류:

루트 결정: 최단경로 vs Special 우회 vs Exit 인접 Elite 우회

자원 할당: 회복 포션을 지금 쓸 것인가, 다음 층을 위해 아낄 것인가

위험 감수: 정화 스크롤 부족 시 미감정 장비를 낄 것인가

시간 예산: 시간 보너스 사냥에 60초 중 몇 초를 투자할 것인가

### 11.4 Safe Room의 두가지 모드(일반/상점)

1층과 보스 전이 끝난 6층과 11층의 Safe Room에서는 상인이 등장하고 방 테두리에 상품들이 놓여져 있다.

# 13. 메타프로그레션 / 챌린지 모드

### 13.1 설계 철학

왜 챌린지 모드인가 1회 클리어는 입문이고, 챌린지 모드부터가 진짜 게임이다. 같은 던전을 서로 다른 제약 아래 다시 통과하게 만들어 리플레이 가치를 만들어낸다.

챌린지 모드는 다음 원칙으로 설계된다.

의도된 비대칭: 챌린지의 난이도와 점수 배수는 균형을 맞추지 않는다. 편한 챌린지로는 적당한 점수, 불쾌한 챌린지로는 폭발적인 점수를 얻도록 설계해 고점 추구 플레이어가 불편함을 선택하게 만든다.

곱셈 누적: 챌린지 배수는 곱셈으로 누적되어 다중 활성화 시 점수가 기하급수적으로 증가한다.

시드와의 결합: 동일 시드 + 동일 챌린지 조합에서 점수 경쟁이 성립하여 객관적 비교가 가능하다.

회차 내 완결성: 챌린지 모드는 메타프로그레션이 아니다. 빌드는 매 회차 죽고, 다음 회차에 누적되는 것은 점수와 기록뿐이다.

### 13.2 챌린지 종류

챌린지는 1층 Safe Room 입장 직전 선택 화면에서 토글한다. 한 번 시작한 런에서는 챌린지 구성을 변경할 수 없으며, 활성 챌린지 수에는 제한이 없다.

| 챌린지 | 변경 내용 | 비고 |
| --- | --- | --- |
| 시간 압박 | 층당 제한시간 60초 → 45초 | 모든 행동 시간 소모는 동일 |
| 보스 강화 | 보스 HP/공격력/방어력/회피/정확도 상승, 패턴 변화 추가 | 5.1 보스 표 괄호값 적용. 패턴 변화는 5.1.x에 별도 기술 |
| 빈약한 강화 | 강화 주문서 등장 수량 감소 (Area당 3개 → 2개) |  |
| 회복 봉인 | 회복 포션 효과 무효 (드랍은 정상, 사용 시 효과 0) | 흡혈 마법, 음식, 건강한 몸 특성은 정상 작동 |
| 파편 봉인 | 몬스터 생명 파편 드랍 없음 | 처치 동기가 시간 보너스/경험치로 한정 |
| 시야 제한 | 기본 시야 -2 (Dark Feeling과 누적, 최소 시야 2 유지) | 횃불, 지도 스크롤, 심안 포션 가치 상승 |

### 13.3 점수 시스템

기본 점수는 다음 항목의 합으로 산출한다.

| 항목 | 수치 | 비고 |
| --- | --- | --- |
| 도달 층 보너스 | 도달 층 × 100 | 사망한 층까지 포함 |
| 잔여 시간 보너스 | 각 층 잔여 시간 합산 × 1 | 빠르게 클리어할수록 누적 |
| 보스 클리어 보너스 | 500 / 1000 / 2000 | 5층 / 10층 / 15층 각각 |
| 처치 보너스 | 처치한 몬스터의 시간 보너스 수치 합 | +3/+5/+10초 보너스 그대로 점수 환산 |

### 13.4 시드 챌린지

1.1에 명시된 시드 기반 결정론적 생성을 활용해 동일한 조건에서의 점수 경쟁을 가능하게 한다.

| 모드 | 설명 | 시도 제한 |
| --- | --- | --- |
| 자동 시드 | 매 런마다 무작위 시드로 시작 (기본 모드) | 무제한 |
| 시드 입력 | 플레이어가 임의 시드 코드를 입력해 시작 | 무제한 |
| 일일 챌린지 | 매일 모든 플레이어에게 동일한 시드 + 챌린지 조합 제공 | 하루 1회 |
| 공유 시드 | 시드 코드와 챌린지 구성을 함께 공유하여 친구와 경쟁 | 무제한 |

일일 챌린지와 공유 시드는 점수 랭킹 비교의 핵심 동기다. 동일 시드는 동일 맵·아이템·몬스터 배치를 보장하므로, 점수 차이는 전적으로 플레이어의 판단력으로 귀결된다.

### 13.5 회차 간 진행

챌린지 모드는 회차 간 빌드 누적을 허용하지 않는다.

| 분류 | 요소 | 비고 |
| --- | --- | --- |
| 보존 | 골드 (사망 시 50%) | 8.5 참조 |
| 보존 | 골드 (악마의 뿔 보유 시 100%) | 5.1.3 참조 |
| 보존 | 챌린지별 클리어 기록 | 트로피/뱃지 |
| 보존 | 시드별 최고 점수 | 일일 챌린지 포함 |
| 비보존 | 인벤토리 아이템 전체 | — |
| 비보존 | 장비 강화 수치 | — |
| 비보존 | 특성 포인트 / 캐릭터 레벨 | — |

디자인 철학 회차 간에 누적되는 것은 점수와 기록뿐이다. 빌드는 매번 죽고 다시 태어난다. 이는 의도된 설계다. 한 회차가 자기 안에서 완결되어야 짧은 세션(15~25분)의 의사결정이 무겁게 다가오고, 사망의 비용도 명확해진다. Stolen Time은 메타프로그레션 게임이 아니라 챌린지 게임이다.
# 14. Steam 도전과제

### 14.1 설계 철학

도전과제는 신규 콘텐츠를 만들지 않는다. 이미 존재하는 3보스·15층·챌린지 6종·점수 시스템을 재조명하는 장치이며, 플레이어에게 다음 목표를 제시하는 역할만 한다. 따라서 도전과제 달성을 위한 전용 몬스터·아이템·방은 추가하지 않는다.

3개 계층으로 구성한다.

| 계층 | 목적 | 비중 |
| --- | --- | --- |
| 진행 | 게임을 끝까지 봤는지 표시. 대부분의 플레이어가 획득 | 4종 |

### 14.3 통계 (Stat)

파트너 사이트 Stats 탭에 등록하는 누적 통계는 1종으로 고정한다. 통계가 늘어나면 서버 동기화 실패 시 복구 비용이 커지므로, 런 단위로 판정 가능한 조건은 통계를 쓰지 않는다.

| Stat API Name | 형식 | 용도 | 기본값 |
| --- | --- | --- | --- |
| stat_total_kills | INT | 누적 처치 수. ACH_TOTAL_KILLS_1000의 진행도 | 0 |

통계 커밋은 런 종료 시점(사망 또는 점수 확정) 1회로 제한한다. 처치마다 커밋하면 Steam 레이트 리밋에 걸린다.

### 14.4 해금 제외 규칙

시드를 직접 입력한 런은 런 결과 기반 도전과제를 해금하지 않는다. 13.4의 랭킹 제외 정책과 동일한 기준이며, 유리한 시드를 반복 탐색해 점수·클리어 도전과제를 우회하는 것을 막는다.

| 분류 | 시드 직접 입력 런 | 근거 |
| --- | --- | --- |
| 진행 / 챌린지 / 숙련 (14.2) | 해금 안 함 | 시드 탐색으로 난이도 우회 가능 |
| 탐험 / 누적 (14.2) | 해금함 | 시드와 무관한 1회성 상호작용 |

일일 챌린지 런은 시드가 고정이지만 플레이어가 고른 시드가 아니므로 전 항목 해금 대상이다.

### 14.5 문턱 수치

플레이 데이터 확보 전 잠정값이다. 출시 전 점수 분포를 보고 확정한다.

| 도전과제 | 문턱 | 조정 시 고려사항 |
| --- | --- | --- |
| ACH_SCORE_10K | 10,000점 | 챌린지 없는 클리어 런의 평균 점수 부근 |
| ACH_SCORE_30K | 30,000점 | 13.3 배수가 1.5^6 = 약 11.4배이므로 챌린지 다수 런에서는 쉽게 도달 |
| ACH_KILLS_RUN_50 | 50처치 | 시간 제한상 전투 편중 빌드에서만 도달 |
| ACH_RESIDUAL_300 | 300 | 층당 평균 잔여 20초 × 15층 기준 |
| ACH_TOTAL_KILLS_1000 | 1,000처치 | 약 20~30런 분량 |

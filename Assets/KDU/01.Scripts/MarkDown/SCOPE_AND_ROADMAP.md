## 0. 현재 단계 — Steam 출시 버전 (2026-09~)

비버롹스 출품은 완료. 지금은 **1인 개발로 Steam 출시 버전** 제작 단계다(팀은 출품까지). 아래 1~4절의 출품 기준 내용 중 "출품 후(P2)"로 미뤘던 항목은 출시 스코프 후보로 재분류한다. 3·4절의 팀원별 분담·마일스톤은 출품 당시 기록.

### 출시 스코프 확정 항목
- **일일 시드 챌린지 + Steam 리더보드** — KST 날짜마다 보드 1개(`daily_yyyyMMdd`), 자정에 새 보드로 전환(24시간 유지). 날짜 시드 고정, 재도전 허용(최고 기록 유지). **(예정) 챌린지는 그날 모든 플레이어가 같은 조합으로 켜진 채 시작하고, 어떤 제약인지는 플레이어에게 숨김** — 현재 구현은 챌린지 없음. 자정 넘긴 런은 유예 시간 이내면 시작일 보드에 업로드.
- **전체 랭킹 (Steam, 모든 유저 통합)** — 보드 `global_alltime` 1개, 최고 기록 유지. 랭킹 창 탭 3개: 전체 Top 100 / 내 기록(로컬 톱30, 행마다 `이름 | 세계 순위 | 로컬 순위 | 층 | 점수` — 세계 순위는 전체 Top 100 대비 해당 점수의 순위, 일일 기록은 `-`) / 일일.
- **순위 표기** — `1st, 2nd, 3rd, 4th …`. Steam 랭킹은 100위 밖이면 `NA`.
- **시드 직접 입력 런은 기록 제외** — 로컬 기록판·전체 랭킹 모두 저장 안 함.
- **일일 런은 일일 보드에만** — 챌린지 배수(1.5~5배)가 붙어 일반 런과 점수 기준이 달라 로컬 기록판·전체 랭킹에서 제외.

## 1. 스코프 락 (Scope Lock)

**게임 범위는 3영역(15층)·3보스 전부.** 출품 때 확정, 출시 버전도 동일. 영역 수로 스코프를 줄이지 않는다.

대신 스코프 락의 방어선은 **영역당 콘텐츠 깊이**로 이동한다. "3영역 다 넣는다"가 무한 스코프가 되지 않도록 다음을 GDD 범위로 고정:

- 영역당 몬스터 종류 = **GDD 10장 로스터로 고정.** 추가 X.
- 아이템/포션/스크롤/마법/저주 풀 = **GDD 9장으로 고정.** 추가 X.
- 방 종류 = **GDD 6.2.1(Special 5종) / 6.2.2(Secret 4종)으로 고정.** 발명 X.
- Floor Feeling = **3종 고정** (Hazard/Traps/Dark).

GDD에 없는 건 **혼자 추가 안 함.** "이거 추가하면 더 좋을 텐데" 충동 발생 시:
1. 출시 일정에 들어가는지 자문
2. 안 들어가면 → `BACKLOG.md`에 적고 출시 후로
3. 들어간다면 → **GDD 먼저 갱신** 후 구현 (코드부터 추가 X)

**자주 추가하고 싶어지는 함정**: "유물 시스템 미리"(P2) / "다국어"(후순위) / "몬스터·아이템 더"(GDD 풀 고정) / "보스 패턴 더 화려하게"(80% 먼저, 폴리싱은 M4).

### 챌린지 모드 스코프 (GDD 13장)
- **출품 빌드 포함 (완료)**: 챌린지 토글 6종 + 곱셈 점수 + 챌린지 선택/결산 UI + 시드 입력.
- **출시 버전 포함**: 일일 시드 챌린지 + Steam 랭킹 (0절 참조).

## 3. 일정 최대 리스크 — 보스 3종 (출품 기준 — 기록용)

**LSH 혼자 보스 3종을 4개월에 빼는 것이 단일 최대 리스크.** 보스 하나가 다른 팀원 콘텐츠 여러 개 분량(감시자 레이저 3패턴, 불사왕 광폭화 2페이즈, 하데스 무적+비석 기믹). → 보스를 Month 2부터 일찍 착수, 영역당 1보스씩 분산.

### 보스 폴백 전략 (전략 A — 확정)
3종 모두 **기본 패턴까지 먼저 완성(80%)**, 화려한 페이즈(감시자 레이저3 / 불사왕 광폭화 / 하데스 비석 기믹)는 **Month 4 폴리싱 버킷**으로. 부스 데모에서 "보스 3개 다 등장"은 사수, 폴리싱은 일정 보고 채움.

추가 안전장치: 보스층 맵은 **고정 맵**이라 절차생성 의존이 없음 → 보스 작업이 맵 생성 진척과 독립적으로 굴러갈 수 있음. LSH는 Month 1에 보스 공통 골격(BossBase + 페이즈 enum + 텔레그래프 연동)부터.

## 1. 스코프 락 (Scope Lock)

**출품 범위는 3영역(15층)·3보스 전부.** 이건 확정. 영역 수로 스코프를 줄이지 않는다.

대신 스코프 락의 방어선은 **영역당 콘텐츠 깊이**로 이동한다. "3영역 다 넣는다"가 무한 스코프가 되지 않도록 다음을 GDD 범위로 고정:

- 영역당 몬스터 종류 = **GDD 10장 로스터로 고정.** 추가 X.
- 아이템/포션/스크롤/마법/저주 풀 = **GDD 9장으로 고정.** 추가 X.
- 방 종류 = **GDD 6.2.1(Special 5종) / 6.2.2(Secret 4종)으로 고정.** 발명 X.
- Floor Feeling = **3종 고정** (Hazard/Traps/Dark).

GDD에 없는 건 본 개발 중간에 **추가 안 함.** "이거 추가하면 더 좋을 텐데" 충동 발생 시:
1. 4개월 일정에 들어가는지 자문
2. 안 들어가면 → `BACKLOG.md`에 적고 출품 후로
3. 들어간다면 → 팀 회의 후 결정 (혼자 추가 X)

**자주 추가하고 싶어지는 함정**: "유물 시스템 미리"(P2) / "다국어"(후순위) / "몬스터·아이템 더"(GDD 풀 고정) / "보스 패턴 더 화려하게"(80% 먼저, 폴리싱은 M4).

### 챌린지 모드 스코프 (GDD 13장)
- **출품 빌드 포함**: 챌린지 토글 6종 + 곱셈 점수 + 챌린지 선택/결산 UI + 시드 입력. (부스 시연 리플레이 후킹 포인트)
- **출품 후 (P2)**: 일일 챌린지, 공유 시드 랭킹. → `BACKLOG.md`

## 2. 완벽주의 금지

- 한 번에 80% 완성도로 끝내고 다음 작업으로
- 폴리싱은 4개월차에 한꺼번에
- 미완성 시스템도 다른 시스템이 의존할 수 있게 인터페이스/이벤트만 먼저 잡아두기
- "이 부분 더 멋있게 짤 수 있는데"는 `BACKLOG.md`에 기록 후 패스

## 3. 일정 최대 리스크 — 보스 3종

**LSH 혼자 보스 3종을 4개월에 빼는 것이 단일 최대 리스크.** 보스 하나가 다른 팀원 콘텐츠 여러 개 분량(감시자 레이저 3패턴, 불사왕 광폭화 2페이즈, 하데스 무적+비석 기믹). → 보스를 Month 2부터 일찍 착수, 영역당 1보스씩 분산.

### 보스 폴백 전략 (전략 A — 확정)
3종 모두 **기본 패턴까지 먼저 완성(80%)**, 화려한 페이즈(감시자 레이저3 / 불사왕 광폭화 / 하데스 비석 기믹)는 **Month 4 폴리싱 버킷**으로. 부스 데모에서 "보스 3개 다 등장"은 사수, 폴리싱은 일정 보고 채움.

추가 안전장치: 보스층 맵은 **고정 맵**이라 절차생성 의존이 없음 → 보스 작업이 맵 생성 진척과 독립적으로 굴러갈 수 있음. LSH는 Month 1에 보스 공통 골격(BossBase + 페이즈 enum + 텔레그래프 연동)부터.
